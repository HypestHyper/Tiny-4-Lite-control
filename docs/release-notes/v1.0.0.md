First release of Tiny 2 Lite Control, a control app for the OBSBOT Tiny 2 Lite on Linux.

It covers the gimbal (pan, tilt, zoom, limits), picture settings, AI tracking and gestures, presets, the
microphone and power settings, with a main window, a quick-controls window and a preview window.

**Install**
```sh
chmod +x Tiny4LiteControl-x86_64.AppImage
./Tiny4LiteControl-x86_64.AppImage app install
tiny4lite-control service install systemd --write
systemctl --user daemon-reload && systemctl --user enable --now tiny4lite-control.service
```
The [README](https://github.com/HypestHyper/Tiny-4-Lite-control#installation) has the details and the other ways to start the service. Every change is in [CHANGELOG.md](https://github.com/HypestHyper/Tiny-4-Lite-control/blob/main/app/CHANGELOG.md).
