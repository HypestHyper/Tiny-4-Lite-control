The first release of Tiny 2 Lite Control, a Linux app for the OBSBOT Tiny 2 Lite.

**Highlights**
- Pan and tilt with a joystick, 1° steps, gimbal limits and a live 3D model of the camera.
- Picture controls: exposure, white balance, focus, HDR, zoom, field of view and a capture mode that stays as you chose it.
- AI tracking modes, tracking speed, a tracking area with a return position, and hand gestures.
- Presets for everything, with six preset buttons by the joystick.
- Microphone controls with a level meter, sleep timers, a Studio virtual camera, backups and update checks.
- A full window, a quick-controls panel and a pop-out preview, each with its own window class.

**Install**
```sh
chmod +x Tiny4LiteControl-x86_64.AppImage
./Tiny4LiteControl-x86_64.AppImage app install
tiny4lite-control service install systemd --write
systemctl --user daemon-reload && systemctl --user enable --now tiny4lite-control.service
```
The [README](https://github.com/HypestHyper/Tiny-4-Lite-control#installation) has the details and the other ways to start the service. Every change is in [CHANGELOG.md](https://github.com/HypestHyper/Tiny-4-Lite-control/blob/main/app/CHANGELOG.md).
